# Balanced Curie--Weiss phase comparison

This draft publishes the approved raw export from exact circuit probabilities and metrics, averaged across three seeds (410, 411, 412), using the fixed whole protocol. Checkpoints are selected by raw exact profile-TVD: shared development conditions and independent same-fit conditions.

The ancilla and scaling figures retain the old protocol pending runs. The renderer reads `figure_data.json` and writes `curie_phase_comparison_raw.{pdf,png}` to `../../paper/figures` by default. The legacy `curie_phase_comparison_flip.{pdf,png}` alias contains identical raw PDF/PNG bytes for compatibility only.
