# Center the main text on theory and the Ising mechanism benchmark

The main manuscript will contain the estimator theorem, finite-resource
conditional-response characterization, estimator/gradient scaling benchmark,
and PennyLane-Ising conditioning-mechanism benchmark. The Gaussian study is
compressed to one motivating result contrasting profile control with
Bitstring failure; sparse grids, ancilla ladders, permutation twirling,
Condition-count scaling, topology comparisons, and complete negative audits
move to supplementary material. The twirl is removed from the abstract and
conclusion because it is Target-specific post-processing rather than learned
fixed-circuit response.
