# Require a written theorem novelty dossier

Before major Ising compute begins, the internal Theorem novelty gate must
produce a written dossier containing exact theorem statements, assumptions,
and complete proofs; a closest-prior-result matrix built from primary sources;
a precise novelty delta for every theorem; symbolic or numerical sanity checks
and attempted counterexamples; and a claim-to-theorem map for the Abstract and
Introduction. The gate passes only if at least one central finite-resource
conditional-response theorem is correct, is not a direct corollary of known
IQP or Fourier results, and materially supports the fixed-circuit conditioning
claim. An informal author judgment is insufficient.
