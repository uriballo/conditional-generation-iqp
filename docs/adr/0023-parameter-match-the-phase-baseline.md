# Parameter-match the primary phase-conditioned baseline

The Condition-modulated-phase model used in fixed-circuit benefit retention
has the same number of trainable coefficients as the input-conditioned model,
with a preregistered fixed assignment of Condition features to generators.
An intercept-plus-slope phase family that increases parameter count may be run
within the 400-run ceiling, but it is a descriptive upper reference and cannot
define the primary retention denominator.
