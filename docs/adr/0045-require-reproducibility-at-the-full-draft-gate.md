# Require reproducibility at the full-draft gate

A manuscript is not ready for external review until it has an accompanying
reproducibility package containing executable code, frozen configurations and
random seeds, generated Ising coupling instances, target and calibration data,
sampler-audit outputs, raw metrics, analysis and figure scripts, and
theorem-check notebooks. Large trained checkpoints may be stored in a separate
persistent archive linked from the package. Reproducibility work is part of
producing the mature full draft rather than deferred until submission.
