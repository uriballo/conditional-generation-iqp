# Freeze the Ising campaign kill tree

The Ising campaign proceeds only if the internal Theorem novelty gate passes.
If the Visible-only Ising primary fails its representability gate, the team may
run only the already specified exact-objective diagnostic and must then stop
the shared-conditioning campaign. If the 320-run visible-only primary matrix
fails its preregistered benefit-retention or interpolation rules, the Bounded
Ising ancilla extension is cancelled and the manuscript is redirected to a
boundary or negative result. Architecture search, threshold relaxation, and
ancilla rescue are not permitted responses to a failed gate.
